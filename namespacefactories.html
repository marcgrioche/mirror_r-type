Detailed Description

Create an eye entity composed of:

  • parent entity with Position + Eye component
  • outline sprite entity
  • pupil sprite entity

textureOutlineId / texturePupilId can be a path or an id loaded in ResourceManager.

width/height = desired rendered size of the eye (outline) pupilW/pupilH = desired rendered size of the pupil sprite pupilRadius = maximum distance pupil center can move from eye center
